## 5. Git

- Ветки: `<тип>/<короткое-описание>`, ответвление от свежей основной ветки.
- **Коммитить часто, отправлять один раз.** Коммиты бесплатны, проверки — нет.
- Никогда: отправка прямо в основную ветку, принудительная отправка, переписывание
  истории, массовое добавление файлов, коммит секретов.
- Перед отправкой — дешёвые локальные проверки: линтер, типы, точечные тесты.
- Основная ветка вливается в свою ДО финального ревью, не после.

## 6. Инкрементальные коммиты

Коммит после каждой законченной логической единицы, а не «когда всё готово».
Единицы: миграция, доменный тип, контракт запроса/ответа, логика сервиса, обработчик,
компонент, багфикс, тесты, конфиг. Не накапливать больше одной незакоммиченной единицы.

## 7. Рабочие копии

Каждый редактирующий агент работает в собственной рабочей копии репозитория.
Общая копия принадлежит человеку и его IDE — в ней не редактируют.
**Задача не завершена, пока рабочая копия не удалена.** «Смержено» ≠ «сделано».

## 8. Ревью

Перед коммитом крупного или критического изменения запускаются ревьюеры — синхронно,
из той же рабочей копии, по финальному диффу. Порядок: доделать единицу → дешёвые
проверки → ревьюеры → один пакет правок → один повторный прогон.

Находки сортируются по таблице «важность × ось»; отклонить находку — законный исход,
но он записывается один раз в описании PR или в задаче.

## 9. Задачи

Всё, кроме тривиальных правок и горячих фиксов, имеет задачу в трекере со ссылкой из PR.
У задачи есть поле «готово, когда» — одно проверяемое условие.
Пользователь сказал «запиши / потом / вернёмся» — задача заводится сразу, без вопросов.

## 10. Отчёт человеку

После любой значимой работы — короткое резюме обычным языком:

```
Что сделано:   1–3 предложения. Результат, а не реализация.
Где смотреть:  ссылки на PR / задачи / файлы, с фразой контекста к каждой.
Что нашли:     находки и сюрпризы по ходу — даже если уже починили.
Что осталось:  открытые хвосты и развилки для владельца.
```

Последние два блока пропускаются целиком, если писать нечего. Пустой заголовок не оставлять.
Сырой список коммитов — это не отчёт.
