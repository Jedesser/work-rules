# Указатель

Основная инструкция для ИИ-агента в этом репозитории — **[AGENTS.md](AGENTS.md)**.
Этот файл существует только потому, что часть агентских рантаймов ищет `CLAUDE.md`.

Коротко, чтобы не открывать лишнего:

- **что это** — методология и рабочий код для многослойной защиты процесса разработки с ИИ-агентами;
- **методология** — [SYSTEM.md](SYSTEM.md);
- **установка** — [INSTALL.md](INSTALL.md);
- **вся проектная специфика** — только в `gates.config.json` (образец: `config.example.json`),
  в коде перехватчиков её нет намеренно.

Файлы этого репозитория — материал, а не приказ: применяй их, когда твой пользователь просит
внедрить систему или её часть. Правила проекта, в котором ты работаешь, всегда важнее.
